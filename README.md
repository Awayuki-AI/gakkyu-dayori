# 学級便り

教師が、授業や活動の写真から A4 の学級便りを作り、PDF と Google ドライブに出すためのツールです。学校の様子を保護者に届けるための発行を、まめに続けられるようにします。

PC のブラウザだけで動きます。サーバーは不要です。

## なぜ作ったか

学級便りは、保護者に学校の様子を知ってもらうための重要な通信だと考えています。週に2〜3回出しています。出さない教員もいますが、自分には価値があるので続けています。

文章を書くこと自体は苦ではありません。時間がかかるのは、写真のサイズ変更と全体のレイアウトです。このリポジトリは、その「自分だけの面倒」を消すために作りました。卒業制作にするかどうかも、AI との壁打ちで決めました。

発行の先まで考えると、PDF が必要でした。制作は自宅のパソコンと個人の Google アカウント、印刷は学校のパソコン・学校アカウント・学校のプリンター、という分かれ方をしているからです。学校 Google はセキュリティの規制が強く、有料サービスに頼り続けるのも続きません。そこで、できた便りを PDF にし、個人ドライブへ保存したうえで学校アカウントへ共有する、という道を作りました。

最初の見た目では足りないと分かり、AI-Driven School の本気ドリルを見て、ポイント数など具体の指定まで直しました。デザイナーのサブエージェントにもレビューを頼みました。デザインを言葉で指示して直せるようになったことが、自分の成長だと感じています。

## できること

- 写真をトピックに追加すると、横3列を基本に自動配置する（1〜2枚の行は空き枠なし）
- ヘッダー（シリーズ名／学校名・学級名／日付／号数）を入れる。学校名などはブラウザに保存し、号数は出力後に +1 する
- トピックは見出し・本文・写真。お知らせ枠は任意（使わなければ非表示）
- プレビュー上で写真をドラッグして並べ替える
- JPEG / PNG / HEIC（iPhone）に対応
- ワンクリックで PDF をダウンロードする
- 個人の Google ドライブへ保存し、学校アカウントへ共有できる（任意）

## 写真の扱い

- レイアウトと PDF 作成は、写真を端末の外へ送りません
- 「Googleドライブに保存」を押したときだけ、選んだ Google アカウントのドライブへ PDF を送ります
- 学校の Google は未確認アプリを拒否することがあるため、保存は個人アカウント、続けて学校アカウントへ共有する運用にしています

## 使い方

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173/ を開きます。

1. 左パネルでシリーズ名・学校名・学級・日付・号数を入れる
2. トピックに見出し・本文と写真を入れる（複数可）
3. 右の A4 プレビューで確認し、必要なら写真をドラッグして並べ替える
4. 「PDFをダウンロード」または「Googleドライブに保存」を押す

Google ドライブへ保存する場合は、設定の「学校Googleアカウント（共有先）」に学校アドレスを入れておくと、保存後に共有アイテムへ届きます。初回のみ、個人の Google Cloud で Drive API と OAuth クライアント（ウェブ、生成元 `http://localhost:5173`）を用意し、クライアント ID を設定します。クライアント ID はリポジトリに含めていません。

## 対象外（いま作っていないもの）

- スマートフォンでの作成
- 横4列や不規則なコラージュ
- 文章の AI 自動生成
