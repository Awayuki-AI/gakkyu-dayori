# 学級便り

教師向けの学級便り作成ツールです。写真をトピックに追加すると、横3列を基本に自動配置し、PDFをダウンロードできます。

## 特徴

- 写真はブラウザ（端末内）だけで処理し、外部には送信しません
- ヘッダー（シリーズ名／学校名・学級名／日付／号数）
- トピック行（見出し＋本文＋写真）。1〜3枚で空き枠なしのレイアウト切替
- お知らせ枠は任意
- プレビュー上で写真をドラッグして並べ替え
- ワンクリックPDFダウンロード

## 使い方

```bash
npm install
npm run dev
```

ブラウザで表示された画面の左パネルから設定・本文・写真を入れ、右のプレビューを確認して「PDFをダウンロード」を押します。

## 注意

- PCのブラウザ向けです（スマホ非対応）
- タイトル書体は「Yusei Magic」（たぬき油性マジック同系統、ローカル同梱）
- UIは Tailwind CSS、便りのシャボン玉などは一部 CSS
